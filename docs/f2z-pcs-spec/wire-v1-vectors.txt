=================================================

All hex is lowercase and contains no separators. These vectors are normative
for the primitive container/domain/payload encoding, Merkle codec, and positive-difficulty PoW
predicate. The fixtures are codec tests, not a complete proof accepted by
VerifyF2Z.

------------------------------------

followed by K(1) as lo-u64-le, hi-u64-le. There are no Hint records. At this
ledger position, the verifier derives domain code 0x2001 with all three scope
coordinates inapplicable (0xffffffff). The domain and payload size are

Merkle primitive micro-vector
-----------------------------
This tests the row/tree/multiproof codec independently of the deployed level
geometry; it is not an accepted protocol proof. There are four leaves of one K
element each, C[q,0]=q for q=0,1,2,3, with each K element encoded as a
16-byte little-endian word. The opened query set is [0,1,3]. At depth zero,
0 and 1 are an active sibling pair and emit nothing; query 3 emits sibling
leaf 2. At depth one both parents are active. Thus M=1 and the only proof
digest is leaf_hash[2].
