\subsection{Typed objects and algebraic domains}
\label{sec:public-objects}

An execution is determined by public parameters, an application statement, a
derived PCS statement, a commitment, and local prover state:
\begin{equation}
 \begin{aligned}
 \mathsf{pp}
   &:=(\mathsf{domains},\varphi,\psi,\mathcal C,\mathsf{hash},
       \mathsf{transcript},\mathsf{profile}),\\
 x_{\rm app}&:=(\bm x,\bm p,\bm I,(t,s,W),g),
 &x_{\rm core}&:=((t,s,W),\mathsf{claim},g),\\
 \mathsf{com}&:=(\rho),\\
 \mathsf{st}_P&:=(\bm f,D,\bm b,\Bbit,P,O,\mathsf{tree}).
 \end{aligned}
 \label{eq:public-objects}
\end{equation}
Here $(\bm x,\bm p,\bm I)$ specifies the public PIMSAT instance of
Section~\ref{sec:encoding}.  The application PIOP derives
$\mathsf{claim}$ and hence $x_{\rm core}$; neither is trusted as an independent
prover input.  The commitment is public before the first PIOP challenge, and
$\mathsf{st}_P$ is never transmitted.

Abstractly, $R_M$ and $R$ are commutative unital rings, $M$ is a finite free
$R_M$-module, and $N$ is an $R$-module.  Write
$\iota_A:\Z\to A$ for the canonical integer map of any unital ring $A$;
in particular, $\iota_R(b)=b1_R$ for $b\in\bitsset$.  Whenever $N$ is
scalarized, it is finite free with a
fixed basis, or the profile supplies a separating family of $R$-linear
functionals.  A public unital ring homomorphism $\varphi$ and a
$\varphi$-semilinear public map $\psi$ satisfy
\[
 \varphi:R_M\to R,\qquad \psi:M\to N,\qquad
 \psi(ax+by)=\varphi(a)\psi(x)+\varphi(b)\psi(y)
\]
connect the witness and evaluation domains.  Packing uses
$\Fbin\cong\mathbb F_{2^\kappa}$ with an ordered $\Ftwo$-basis
$(\beta_v)_{v<\kappa}$ and a linear code $\mathcal C$ over $\Fbin$; any
padding to a multiple of $\kappa$ is canonical and statement-bound.

The concrete mod-$q$ profile fixes
\begin{equation}
 R=\Fq,\quad q=2^{100}-15,\qquad
 \Fbin=\K=
 \Ftwo[X]/(X^{128}+X^7+X^2+X+1)
 \cong\mathbb F_{2^{128}}.
 \label{eq:concrete-domains}
\end{equation}
Write $\pi_2:\Z\to\Ftwo$, $\pi_q:\Z\to\Fq$, and
$\operatorname{can}_q:\Fq\to[0,q)$.  Linear evaluations are in $\Fq$;
packing, product reductions, and commitment openings are in $\K$.
Its wire identifier, canonical encodings, transcript and Merkle algorithms,
recursive-opening configuration, and PoW schedule are fixed by
Section~\ref{sec:wire-profile}; they are not runtime-selected proof fields.
The exact constrained-code transform that produces the committed matrices is
selected by the statement-bound $\mathsf{code\_profile\_id}$ and is unsupported
unless that identifier resolves to a published canonical construction.
