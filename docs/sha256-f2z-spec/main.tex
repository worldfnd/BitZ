\begingroup\footnotesize
\textbf{Scope.} This profile proves a public chain of SHA-256 compression
calls, including feed-forward.  It commits only the base witness $f$, derives
the virtual bit tensor $h$, and instantiates the eleven reductions ending in
the F2Z PCS opening.  SHA padding, private messages, and the internals of the
named GKR and Ligerito subprotocols are outside this document.

\textbf{Core-profile delta.} \coreprofileid\ is a reserved, non-resolving
candidate for a new top-level wire/core profile.  It replaces the generic PCS
ProfileID in the host header and tag \code{0x0001}, and replaces direct tag
\code{0x0003} with tag \code{0x1003}.  It also enables the generic PCS
LinCheck tags \code{0x4002/0x4103} and the singleton tag-\code{0x4001}
terminal gate; all other inherited byte rules remain unchanged.  It must not
resolve to acceptance until the virtual partial-core ledger and the integrated
LinCheck/ring fixtures in G6 and G7 are frozen.
