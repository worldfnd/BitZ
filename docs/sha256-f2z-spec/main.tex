\textbf{Scope.} This profile proves a public chain of SHA-256 compression
calls, including feed-forward.  It commits only the base witness $f$, derives
the virtual bit tensor $h$, and instantiates the eleven reductions ending in
the F2Z PCS opening.  SHA padding, private messages, and the internals of the
named GKR and Ligerito subprotocols are outside this document.
